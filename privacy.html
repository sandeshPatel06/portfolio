Privacy Policy

Privacy Summary: This website is the personal professional developer portfolio of Sandesh Patel. We are committed to a strict privacy-first standard. We do not track visitors across the web, sell user data, or use advertising cookies.

1. Scope & Website Purpose

This Privacy Policy applies to the personal developer portfolio website of Sandesh Patel (accessible at sandesh-portfolio.pages.dev and related deployment domains). The portfolio showcases personal software engineering projects, technical skill sets, professional timeline, project code repositories, and live web demonstrations.

2. Data Collected & How It Is Obtained

Because this portfolio operates primarily as a static site, data collection is kept to an absolute minimum:

  • Contact Form Inquiries Formspree API: When you submit a message through the contact form, the details you enter (your name, email address, subject, and message) are transmitted securely via Formspree to enable Sandesh Patel to reply directly to your inquiry.
  • Direct Email Communications: If you email sandeshpatel.sp.93@gmail.com, your email address and message thread are stored securely in email inbox for professional correspondence.
  • UI Theme Preference Browser Local Storage: We use your browser's local storage (localStorage.getItem('theme')) exclusively to store your visual theme selection (Dark Mode vs Light Mode). This data never leaves your device.
  • Resume Preview Modal Google Drive PDF Viewer: Viewing the embedded PDF resume modal loads the document securely via Google Drive preview services. No personal identifiers are gathered by this portfolio when you view or download the resume.

3. Use of Collected Information

Any information voluntarily provided by visitors is used solely for professional engineering purposes:

  • Responding to job opportunities, freelance inquiries, and technical collaboration requests.
  • Maintaining user interface settings (such as theme preference and modal previews).
  • Ensuring overall site accessibility, security, and performance.

4. Third-Party Services & Project Demos

This portfolio links to external third-party services and live project deployments owned or managed by Sandesh Patel:

  • GitHub & Code Repositories: Project source code links point to GitHub (github.com/sandeshPatel06).
  • Live Project Demos & Hosting: Web applications and portfolio pages are hosted on Cloudflare Pages (sandesh-portfolio.pages.dev) and GitHub Pages (sandeshpatel06.github.io).
  • Social Media Profiles: Links to professional profiles on LinkedIn and Instagram.

Please note that third-party services operate under their own respective privacy policies. We encourage visitors to review their privacy disclosures when leaving our site.

5. Web Analytics & Cookies

This website uses Cloudflare Web Analytics to view anonymous traffic statistics (such as page views and general visitor referrers). Cloudflare Web Analytics is privacy-first, does not use cookies, does not collect personal identifiers, and does not follow visitors across different sites.

We do not use advertising cookies, third-party marketing beacons, or cross-site behavioral tracking scripts.

6. Security Measures

We take web security seriously. All connections to this portfolio are encrypted over HTTPS (TLS). Standard web server protections are maintained by our hosting infrastructure to prevent unauthorized access or malicious traffic.
